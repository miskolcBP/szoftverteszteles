# Római szám átalakító

Az 1 és 3999 közötti egész számokat alakítja át római számokká. Érvénytelen bemenetre hibaüzenetet ad.

## Használat

Nyisd meg az `index.html` fájlt a böngészőben. Írd be a számot, majd nyomd meg az Átalakít gombot vagy az Entert.

## Tesztek

Nyisd meg a `tests.html` fájlt a böngészőben. A QUnit helyben van, internet nem kell.

## Fájlok

- `roman.js` – az átalakító
- `roman.test.js` – a tesztek
- `index.html` – a program
- `tests.html` – a tesztek futtatása
